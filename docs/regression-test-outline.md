# OwlPDF 回归测试用例大纲

> 目标：在停止激进开发、进入冻结与发布阶段后，用可重复的测试用例提高稳定性。本文先定义分类与大纲，后续在每个分类下逐步补充具体用例。

## 一、用例设计原则

### 单点用例

单点用例验证一个独立操作是否可用。它关注的是某个入口、按钮、菜单项或快捷键本身有没有坏。

示例：

- 打开普通 PDF。
- 点击“适合页面”。
- 点击“适合宽度”。
- 打开设置页。
- 保存当前 PDF。

### 多点用例

多点用例验证多个有关联的操作连续执行后，相关状态是否仍正确。

多点用例必须至少满足一个条件：

- 多个操作修改同一个底层状态，例如 zoom、current page、selection、outline dirty state。
- 后一个操作依赖前一个操作的结果，例如新增目录后保存，搜索后跳转下一处。
- 多个操作组成一个真实用户任务，例如批注、保存、重开校验。
- 多个操作曾经触发过 bug，作为事故回归链路保留。

不满足上述条件的连续点击，不作为多点用例；拆成单点用例即可。

### 用例书写格式

建议每条用例保持可执行、可判断：

```md
- [ ] 操作步骤：打开 PDF → 点击“适合页面” → 点击“适合宽度” → 再点击“适合页面”。
      预期结果：当前页不变，页面不空白，缩放状态正确，工具栏状态同步。
```

## 三、多点用例

- [ ] 适合页面 → 适合宽度 → 适合页面。
- [ ] 放大 → 缩小 → 适合宽度。
- [ ] 适合宽度 → 调整窗口大小 → 下一页。
- [ ] 手动缩放 → 适合页面 → 手动缩放。
- [ ] 双页模式 → 适合宽度 → 单页模式 → 适合页面。

### 2. Page Navigation State

- [ ] 下一页 → 上一页 → 下一页。
- [ ] 首页 → 末页 → 上一页。
- [ ] 跳转目录项 → 下一页 → 回到原目录项。
- [ ] 连续滚动到中间页 → 切换单页模式。
- [ ] 双页模式下跳转首页与末页。

### 3. Search State

- [ ] 搜索关键词 → 下一处 → 上一处。

- [ ] 搜索关键词 → 切换 Tab → 回到原 Tab。

### 4. Selection State

- [ ] 拖选文本 → 复制 → 清除选区。

### 5. Outline Dirty/Save State

- [ ] 修改设置 → 关闭设置页 → 重开设置页。

## 五、事故回归用例

这里记录真实发生过的问题。每修复一个事故，就补一条最小复现链路。

### 1. Qt 标准按钮国际化

- [ ] 中文系统下打开 `QMessageBox::question` 确认框，按钮不显示英文 Yes/No。
- [ ] 中文系统下打开设置页，底部 OK/Cancel/Restore Defaults 由 Qt 标准翻译显示。
- [ ] 打包产物内存在 `qtbase_zh_CN.qm` 和 `qt_zh_CN.qm`。

### 2. macOS Services 崩溃

- [ ] macOS 顶部应用菜单中展开 Services，不崩溃。
- [ ] 运行时 Qt/rpath 不混用 Homebrew Qt 与工程指定 Qt。
- [ ] macOS 不通过 `QApplication::setWindowIcon` 加载 Windows `.ico`。

### 3. 设置页文字截断

- [ ] 打开设置页，切换全部分类，中文说明文字完整显示。
- [ ] 缩小到最小窗口，右侧内容可滚动。
- [ ] 恢复默认确认框按钮和文字完整显示。

## 六、后续维护规则

- 新增功能时，至少补一个单点用例。
- 新增状态或修改状态流转时，至少补一个多点用例。
- 修复崩溃、数据损坏、平台兼容、国际化、布局问题时，必须补事故回归用例。
- 发布前优先跑 P0、高风险数据完整性、macOS 平台集成、事故回归。
- 用例宁可少但可执行，不写无法判断结果的泛泛描述。
